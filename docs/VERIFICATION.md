# 驗證範圍

驗證日期：2026-10-22。目標硬體：Mac17,8 / Apple M5 Pro；系統：macOS 27.0.1。

## v1.0.3（build 6）

- Release 建置及 deep/strict 簽章驗證通過；既有 58 項核心與故障注入測試通過，0 失敗。
- 實際操作預設檔新增、原地修改、重新開啟後保留、空白名稱自動命名及超出範圍拒絕。
- 儲存只改本機資料；運轉中儲存不同數字不會套用到硬體，「目前使用」也不會誤標。
- 預設檔套用後，獨立 SMC 讀回目標為 1900／2000 RPM，即時為 1896／2005 RPM。
- 驗收結束後獨立讀回兩顆風扇皆為系統自動；服務沒有作用中規則、待復原風扇或控制計時器。
- 原有預設檔及選單列只顯示圖示的偏好保留。

此版功能修改集中於預設檔 UI 與本機儲存。公開發行時另外換成自行繪製的 App 與品牌圖示、移除除錯符號及重新簽署；控制服務原始碼仍為 `1.0.2-qc3`，沒有新增背景計時器或加快採樣。上述硬體情境測試來自圖示／符號整理前的相同功能程式碼；公開包另驗證簽章、唯讀 SMC／服務讀回及除錯路徑移除。

## 先前控制驗收與限制

1.0.2 控制邏輯已在上述機型驗證固定轉速、真實 CPU 感測器溫控、八秒心跳逾時、連線中斷、控制程序 SIGKILL，以及睡眠／喚醒通知後的自動復原。qc3 修正診斷時間單位，控制邏輯與已實測 qc2 相同。

睡眠通知路徑驗證不等於長時間深度睡眠驗證。1.0.3 沒有重跑整套長時間睡眠或資源基準；先前短時間資源量測也不代表全天耗電或其他機型保證。

此儲存庫不包含個人偏好、原始機器診斷紀錄或開發暫存檔。
